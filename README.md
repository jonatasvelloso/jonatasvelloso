Construo e opero plataformas de dados em produção de ponta a ponta: ingestão com **Apache Airflow**, transformação com **dbt Core** em **Arquitetura Medallion** e **Data Warehouse dimensional** em PostgreSQL e Oracle, com CI/CD e qualidade de dados desde o primeiro commit.

Antes dos dados, foram 7 anos em logística industrial (SAP, OTIF, SLA). Por isso modelo a partir da regra de negócio, não da tabela de origem.

## Impacto em produção

| | |
|---|---|
| **3 empresas → 1 plataforma** | Unificação de dados pós-fusão liderando tecnicamente um time de 5 pessoas |
| **~24h → 1h** | Latência dos indicadores executivos, com 90+ DAGs em Airflow sobre Docker |
| **3–4h/dia → 20 min** | Consolidação manual substituída por pipeline automatizado (60–80 h/mês economizadas) |
| **40 → 2 min (−95%)** | Performance tuning de queries críticas em Oracle via planos de execução |
| **60 relatórios versionados** | CI/CD de Power BI com GitHub Actions, deploy seletivo e aprovação em produção |
